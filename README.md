# Optimización Aerodinámica en F1 mediante Machine Learning 

# Contenido del Repositorio:
- F1_Optimizer_App: Contiene la aplicación interactiva (.mlapp) desarrollada en MATLAB App Designer. Permite procesar la telemetría, entrenar los modelos predictivos y buscar la configuración aerodinámica óptima.
- Códigos para Ferrari_F2004: Códigos fuente (.m) utilizados para la validación y el estudio de escalabilidad del modelo en vehículos históricos.
- Telemetria: Archivos CSV extraídos de Assetto Corsa para poder probar el funcionamiento de los códigos y algoritmos.

 # Instrucciones de uso:
- Monoplazas 2025 y 2026: Ejecutar directamente la aplicación interactiva (F1_Optimizer_App) e interactuar a través de su interfaz.
- Monoplaza Ferrari F2004: Ejecutar los códigos fuente (.m) en orden directamente desde el editor de código o la consola de MATLAB.

# Nota importante: 
El código está configurado específicamente para procesar la telemetría adjunta en este repositorio. Si se desea utilizar una telemetría distinta, será necesario ajustar los parámetros dentro del código.

# F1 Aerodynamics Optimization via Machine Learning 

# Repository Contents:
- F1_Optimizer_App: Contains the interactive application (.mlapp) developed in MATLAB App Designer. It allows for telemetry processing, predictive model training, and optimal aerodynamic setup search.
- Codes for Ferrari_F2004: Source codes (.m) used for validation and scalability study of the model on historical vehicles.
- Telemetry: CSV files extracted from Assetto Corsa to test the functionality of the codes and algorithms.
  
# Instructions for use:
- 2025 and 2026 Cars: Run the interactive application (F1_Optimizer_App) directly and interact through its interface.
- Ferrari F2004 Car: Run the source codes (.m) sequentially directly from the code editor or the MATLAB console.

# Important note: 
The code is specifically configured to process the telemetry attached in this repository. If different telemetry is to be used, it will be necessary to adjust the paths and parameters within the code.
